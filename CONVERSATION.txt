STACK
-----
- Frontend: plain HTML/CSS/JS, no framework. Design tokens in assets/css/main.css.
- Backend: Flask + SQLite (stdlib sqlite3, no ORM), Flask-Cors, gunicorn (prod).
- Auth: token sessions (Authorization: Bearer), passwords hashed (scrypt).
- Frontend pattern: backend-first with silent localStorage fallback (offline demo
  mode). Key file: assets/js/api.js (auto-detects backend via /api/health,
  same-origin default, localStorage "minco_api_base" override).
